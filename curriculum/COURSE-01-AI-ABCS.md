# Course 01 — AI ABCs & Basics (FREE)

**Audience:** beginners. **Outcome:** use AI confidently for one real task, understand limitations, and check results.

| Lesson | Duration | Deliverable |
|---|---|---|
| 1. What AI is and is not | 5m | One accurate use case |
| 2. Models and assistants | 7m | Comparison of two tools |
| 3. Tokens and context | 6m | Estimate input/output usage |
| 4. Prompting clearly | 8m | Before/after prompt |
| 5. Checking AI claims | 7m | Verify three statements |
| 6. Privacy and permissions | 8m | Redacted safe prompt |
| 7. Everyday workflow | 10m | Task process map |
| 8. Measure improvement | 8m | Baseline and follow-up |

**Course description:** New to AI? Learn what it can and cannot do, how tokens work, how to ask better questions, check answers, protect private information, and improve one everyday task. No coding required. Short practical lessons, demonstrations and exercises.

## Repeatable lesson template
Learning objective → 2-minute concept → screen demo → common mistake → learner exercise → verification checklist → feedback question.

## Completion project
Document one repetitive task, baseline time and quality, test an AI-assisted approach, compare results and disclose limitations. Do not imply guaranteed savings.

## Future tracks
Everyday AI; Small Business Workflows; Token Economics; AI Security & Agent Safety. Expand according to member questions and evidence.
